# 角色、动作与场景制作规格

状态：规格与概念初稿已制作；用户授权imagegen CLI/API备用方式。分层角色、绑定与正式动作尚未制作；概念图审核单列，不视为可用游戏资产。

## 烬刃基准

5 头身、视觉高 112，头高22.4、肩宽30、躯干32、骨盆14、腿44.8；尺寸为初始比例指南，姿势审核后冻结。碰撞 H=96、宽32；原点脚底中心，骨盆在 (0,-48)，主手待机约(18,-54)。短刃从柄到尖约0.7H，披肩向后，右手持刃；镜像检查护手与披肩身份。

配色：灰黑头发 #292C35，骨白内衬 #D9CFB9，锈红披肩 #A74437，暗蓝灰护甲 #46505E，余烬点缀 #EAA45B；大亮块用于角色轮廓，点缀不盖敌人预警。轮廓边缘清晰、手绘体积与克制高光，避免像素风和几何替代。

源层必须包含头/颈/躯干/骨盆、左右上臂/前臂/手、大腿/小腿/脚、前后发、衣摆、披风、武器；关节遮盖不拉伸。挂点为 hand_main、hand_off、weapon_grip、weapon_tip、muzzle、head、feet、hurt_torso。双手武器约束副手触柄；图集统一锚点和留边。

阶段1冻结模型在 output/imagegen/emberblade-model-v04.png，含三视图、表情、握持、色板和标尺；标尺不能替代实际比例测量。关键姿势验收如下，生成结果和缺口见docs/testing/stage-01-art.md：

| 姿势 | 发力/轮廓验收 |
| --- | --- |
| 待机 | 固定脚底、重心前移、单独胸腔与衣摆呼吸 |
| 跑步接地 | 前脚负重、后脚蹬伸，接地不滑 |
| 起跳 | 膝髋蹬伸，不延迟玩法起跳 |
| 最高点 | 收腿与衣发滞后，不冻结物理 |
| 落地 | 脚→膝→骨盆→上身缓冲 |
| 攻击预备 | 扭髋蓄势，武器不穿掌 |
| 命中 | 蹬地→髋→肩→手，刀刃到有效区 |
| 收势 | 武器惯性、重心回收，可取消窗明确 |
| 翻滚 | 缩身、运动重心与恢复，不关闭实体碰撞 |
| 受击 | 从伤害源方向失衡，有恢复姿态 |
| 死亡 | 失衡、倒地、停止，不用透明渐隐替代 |

完整动作预算遵循附件 A；阶段 2 还须起步、急停、地面转向、上升/下降、空中攻击、三段连击、独立重击、交互、出生与结算。每动作记录总时长、预备/生效/恢复、事件、取消、转向、位移、命中实例、轨道与审核。轻刃一击初值 0—70/70—130/130—300ms，150—270ms 接连击，150ms 后可闪避；后两段独立设计。

## 1280×720 比较板

同屏以视觉高112的烬刃、追击者约108、射手约120、铸炉守卫首领约260比较剪影；主角短披肩、近战前倾厚臂、射手后仰长武器、首领宽肩低重心。黑剪影、灰度、暗场都需审核。不可只放大展示立绘。

## 三区域与 UI

| 区域 | 材质/色彩 | 光源与层次 | 交互语法 |
| --- | --- | --- | --- |
| 废弃铸坊 | 锈铁、炭黑、暗砖 | 暖炉光；远烟囱、中景梁架、清晰石台 | 铜环出口、金色交互边线，危险锯齿轮廓 |
| 风蚀回廊 | 灰砂岩、褪绿铜 | 冷月/斜风；远塔、中景断拱、平台亮沿 | 风旗指方向，陷阱用脉冲+尖齿 |
| 星灰圣所 | 靛蓝石、银灰晶 | 冷星光/弱暖火；远穹顶、中景符印 | 环状传送与菱形祭台，敌弹红色+尖头 |

UI 为暗石底、骨白正文、铜线分区；中文字体须有可分发许可，阶段 2 选型并登记。生命/闪避/技能位置稳定；危险不只用颜色区分。背景亮度弱于人物，前景不遮战斗；视差低频，光粒子不能盖预警。
