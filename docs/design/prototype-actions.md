# 固定房间原型参数与状态

世界单位：碰撞H=96，宽32；视觉占位约112。game/action_data.gd为唯一动作参数来源，均为固定初值，尚未真人调参。

| 参数 | 定值 |
| --- | --- |
| 移动 | 480单位/s = 5H/s；加速3200、刹车4000单位/s² |
| 重力/跳跃 | 2200单位/s²，起跳-960单位/s；松键上升速度截至-360 |
| 容错 | 土狼100ms，跳跃/连击输入缓冲120ms |
| 闪避 | 总长340ms，速度760，冷却720ms；40—200ms无敌 |
| 受击 | 硬直220ms，伤害免疫500ms；单个攻击对同一目标一次 |
| 平台下穿 | 220ms只移除单向平台层，实体层始终开启 |
| 命中停顿 | 轻35ms，第三击/重击70ms；停顿内收集攻击/重击/跳跃/闪避边沿，恢复后消费 |

| 动作 | 预备/生效/总长ms | 伤害 | 范围/击退 |
| --- | --- | --- | --- |
| slash_1 | 70/60/300 | 14 | 92/210 |
| slash_2 | 90/80/360 | 18 | 105/260 |
| slash_3 | 130/90/480 | 28 | 122/360 |
| heavy | 250/120/700 | 40 | 135/420 |
| air | 80/100/360 | 18 | 95/200 |

预备后发出active事件，时间区间与生效窗相交才查询攻击矩形；不会因跨过某一个瞬间漏整窗。targets_hit按节点实例ID清空/记录；每次start_attack递增攻击实例。实体胶囊、hurt_rect和attack_rect分别定义。

优先级：死亡＞伤害免疫检查/受击中断＞闪避＞攻击＞普通运动。攻击生效结束后可取消至闪避；连击在总时长结束消费120ms输入缓冲，第三击不循环。翻向改变朝向，不重置动作计时/实例。空中普通或技能均使用air动作。

暂停与命中停顿分离：暂停冻结全部战斗时钟，清除缓冲和待消费输入；命中停顿有上限且继续采集边沿。恢复先等移动/动作键和鼠标按钮全部释放，防止持键误攻。实际输入采集与快照路由分开测试。

敌人：近战察觉900、接近140单位/s、90距离开始550ms预警，220ms攻击/700ms恢复；射手440距离瞄准，550ms预警后360单位/s水平弹道；射出前锁方向。精英160HP、180速度、420ms预警/500ms恢复。尸体保留倒地占位，不再攻击。数值偏向验证流程，未完成难度平衡。

无最终动画质量/手感承诺。起步、急停、转向、出生、训练交互、落地持续缓冲及胜利以独立短时覆盖姿态实现，不阻断物理响应；阶段3按附件A交付分层手绘源文件及正式绑定。
