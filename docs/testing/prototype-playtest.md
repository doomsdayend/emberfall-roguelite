# 0.1.0-dev.1 本地原型试玩

开发候选，未发布v0.1.0。Windows x64：保持exe与同名pck在同一目录，双击emberfall-0.1.0-dev.1.exe；不需要Godot编辑器。正常启动会打开游戏窗口；自动验证使用headless或最小化窗口下的GPU离屏子视口。

A/D或左右移动；Space长按高跳/轻按短跳；S或下+Space穿过单向平台；J/鼠标左键三连击；K/鼠标右键重击；Shift/L闪避；E近门交互；Esc暂停；F3调试显示默认关闭。战斗房清敌才开门，训练木桩不锁门；首局从无敌人的安全房开始。

标题设置可开关震屏、调节命中短音音量，仅本次进程有效。没有存档、手柄、重映射或最终手绘资源；英文界面是当前占位。第三击和重击可造成更长命中停顿，独立闪避有冷却，不能穿墙。
