# 阶段 2 · 固定房间动作原型（开发候选）

日期：2026-10-12（Asia/Shanghai）；分支stage-02-action-prototype；版本0.1.0-dev.1。**程序闭环与自动回归已实现；阶段2正式发布门槛尚未关闭。** 未创建v0.1.0 Tag/Release，未进入阶段3量产。

## 已实现

- 标题/开始/音量与震屏设置→安全房→训练区→两个战斗房→精英终战→胜利/死亡→回标题/再开；普通运行默认标题，探针仅由显式测试参数进入。
- 120Hz物理；加速/刹车、长短跳、100ms土狼、120ms缓冲、单向平台下穿、斜坡/墙角；闪避保留实体碰撞。
- 三连击、独立重击/空攻；预备/生效/恢复共用参数表驱动姿态与伤害，同实例去重；受击中断、死亡停止、受击免疫、闪避无敌与冷却。
- 近战追击者、远程射手的预警/锁向/生效/恢复/受击/死亡；精英采用近战原型的强化生命与预警参数，不冒充正式首领。
- 轻重命中停顿、合成短音、粒子、可关闭震屏；肢体弯曲、挥刀回收、收身滚动、受击及倒地为原创程序绘制占位，**不是最终手绘美术**。
- 暂停/失焦冻结物理、AI、弹道和伤害，清空输入并等待全部释放；F3调试框/状态/事件/实例默认隐藏。

参数与优先级见../design/prototype-actions.md；测试见../testing/stage-02-prototype.md；人工检查操作见../testing/prototype-playtest.md。

## 实际证据

源码和独立Windows exe+pck各247项断言通过：20次房间重开、10次夹具流转、10次实际战斗控制器完整通关。固定模拟主循环30/60/120Hz均通过，物理120Hz；不当作真实GPU FPS测试。

真实Intel Graphics/OpenGL子视口离屏捕获16张1280×720图并逐张查看。启动即最小化、不使用headless dummy截图；主窗口状态在日志核验。画面属于当前程序占位原型，不替代概念图或最终美术。没有测量实际最低设备帧率。
