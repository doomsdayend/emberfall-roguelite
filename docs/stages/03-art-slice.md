# 阶段 3 · 首个手绘美术切片

状态：已获准开始；分支从 `stage-02-action-prototype` 的阶段 2 验收提交创建。目标版本 `0.2.0-dev.1`，不代表完整内容量产。

阶段 3 只做一条可验收切片：烬刃主角、短刃、训练场背景和一名近战敌人的正式手绘源文件、分层导出、骨骼绑定与动作接入。阶段 2 的程序姿态继续保留为回退预览，不能冒充最终资产。

交付顺序：

1. 冻结主角与短刃的视觉规格，登记来源、许可、源文件尺寸、透明边界和导出命名。
2. 以阶段 1 的 16 骨骼、8 挂点和 22.4px 头高基准制作分层角色源图；检查站立、起跳、攻击、闪避、受击、死亡和胜利。
3. 接入训练场和一名近战敌人，保留同一碰撞体、攻击时序和命中点；不得因换皮改变战斗参数。
4. 使用 Windows 离屏截图、源图尺寸检查、透明通道检查和 100 次动作事件回归；再进行真人美术可读性检查。

阶段 3 门槛：源文件可编辑且许可已登记；角色与武器不再依赖程序绘制；1 倍尺寸下关节、武器、命中点和危险提示可读；源码、导出包和截图使用同一提交。未满足前不扩展到三角色、完整区域或正式量产。

## 当前进度

已生成并检查两张手绘参考稿（角色1536×1024、训练场1672×941）：烬刃角色设定表和铸坊训练场构图。它们已登记来源、提示词、尺寸与 SHA256，当前状态是 `reference_pending_layering`；不能直接视为最终分层角色、可碰撞背景或已授权商用资产。下一步是人工分层与透明边界审核，再接入阶段 2 的骨骼、碰撞和离屏截图回归。
