# 需求修订 W-001

日期：2026-10-12（Asia/Shanghai）。依据：用户要求按本目录需求分阶段开发，将 Linux 改为 Windows，优先离屏验证；用户明确选择继续使用刚清空的公开仓库。

本修订覆盖所有原始文档中的平台、仓库及文档交付期限制；原文归档不改写。

| 原要求 | 有效要求 |
| --- | --- |
| Ubuntu 24.04 / Linux x86_64 首发 | Windows 10/11 x86_64 桌面；开发与首发均为 Windows |
| Linux 导出、安装、依赖、可执行权限 | Windows 原生 .exe + .pck，ZIP 分发；中文及空格路径、标准用户运行、无编辑器启动 |
| 拟创建私有 emberbound-2d-roguelite | 用户指定公开 doomsdayend/emberfall-roguelite；阶段独立分支，不恢复旧代码 |
| 本次仅文档、不开发 | 本次进入实际阶段开发；仍遵循各阶段依赖与发布门禁 |
| 自动无界面验证 | 默认 headless；需要真实图像时单列 GPU 离屏验证，不自动打开游戏窗口 |

核心玩法、手绘风格、内容数量、8 阶段顺序、附件 A 动作标准、附件 B 可玩版发布记录不变。无窗口测试不替代人工手感、图像和性能验收。Linux 不再作为首发验收目标。

平台最低档暂定：Windows 10 22H2 x64、4 核 CPU、8 GB RAM、支持 OpenGL 3.3 的 GPU、1280×720；这是设计预算，不是已经通过的硬件兼容承诺。Windows 11 为优先验证系统。实际基准硬件另存测试报告。
