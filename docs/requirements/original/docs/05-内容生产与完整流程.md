# 阶段 5 内容生产与完整流程

目标：发布 v0.5.0 Alpha，形成完整三区域流程。新角色、武器和敌人可有明确标记的临时资产，但行为、判定、数据和流程必须完整；角色主动作不能仍是单张站姿。

## 首发内容规模

| 类型 | 目标 | 差异要求 |
| --- | --- | --- |
| 玩家角色 | 3 名 | 轮廓、体态、技能、资源循环和至少部分独特动作 |
| 武器家族 | 6 类 | 短刃、重剑、长枪、弓、符铳、法器，各有独立动作及攻击轨迹 |
| 武器物品 | 至少 18 件 | 每家族至少 3 件，提供实质词条或机制差异 |
| 区域 | 3 个 | 地形、敌人组合、环境危险和配色不同 |
| 房间模块 | 每区域至少 12 个 | 不把仅换色算新模块 |
| 普通敌人 | 9 类 | 近战、远程、飞行、护盾、位移、召唤等行为组合 |
| 精英 | 3 类 | 各区域至少 1 类，有独特攻击或组合 |
| 首领 | 3 名 | 各区域 1 名；最终首领提供完整结局 |
| 增益 | 至少 30 项 | 含 3 条以上机制构筑路线 |
| 代价/诅咒 | 至少 10 项 | 风险、收益、叠加、解除规则可读 |
| 遗物 | 至少 12 件 | 修改机制，明确槽位和互斥 |
| 装备 | 至少 12 件 | 护甲与饰品，图标和穿戴规则明确 |
| 事件 | 至少 8 种 | 有明确选择、收益与代价，不全是文字换数值 |

数量统计以行为或功能不同的条目为准，不重复把换色和品质等级计算为新机制。

## 三名角色定义

- 烬刃：近战平衡型，前压、连击、招架或反击；短发与短披肩轮廓，重心偏前，干脆姿态。
- 风弦：远程敏捷型，蓄力弓与轻型投射、空中调整或位移技能；长发、轻装与长弓轮廓，动作轻快但落地有重量。
- 星契：法术控制型，符印或法器攻击、短距离瞬移或区域技能；宽袖、法器与悬浮装饰，施法有蓄势和收势，不全程漂浮替代步行动画。

角色技能与特性在选择页面描述，支持未解锁预览。所有角色可以使用公共武器家族，但需要兼容的握持插槽与姿态；专属技能不因换武器丢失。共享动画可以复用结构，必须适配体态、服装、身高及发力节奏，不能只换皮。

## 内容生产要求

每项内容有唯一 ID、显示名、图标、说明、基础数值、叠加/解锁规则、音画资产引用和测试状态。武器定义地面、空中、技能及强化交互；挥砍、突刺、箭矢、散射、穿透、弹跳、法术区域具备可识别轨迹。

区域推进规则明确：商店与事件分布有上限，稀有奖励有保底或透明设计，最终流程不因随机生成缺房而中断。新区域进入有短过渡，首领击杀结算与永久奖励不重复。

提供图鉴、基础教程、角色和武器解锁反馈。正式流程至少有一个可理解的结局画面，胜利后可以继续新局，不能停在不可操作的结束文字。

## Alpha 验收

3 角色 × 3 难度分别完成至少 1 次三区域流程；6 个武器家族分别完成至少 1 次全局。极端构筑验证连锁、穿透、反伤、召唤和多投射物同时发生时不会软锁或递归失控。

逐项检查内容表、动画引用和解锁路径；无缺失动作状态、不可读取物品、不可购买商品或首领门卡死。标出尚未精修的资产，但不存在以占位 UI 隐藏玩法缺失的情况。

交付：v0.5.0 构建、全内容目录、解锁和数值表、9 个组合试玩结果、资产缺口清单及更新说明。范围新增必须记录成本和受影响阶段，不无限扩充首发。
