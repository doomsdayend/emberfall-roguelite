# 阶段 6 美术表现与体验打磨

目标：发布 v0.8.0 Beta，让完整游戏拥有统一、灵动、清晰的视觉表现，完成全部正式角色、敌人、武器和环境资产。

## 全量资产精修

附件 A 的造型、动作、转向、握持、碰撞和输出标准覆盖所有主角和敌人。建立资产审核清单；缺省动画、静态死亡、武器错位、未授权音画资产为阻塞问题。逐个替换 Alpha 临时资产，不能只有开始页面精美而游戏本体仍全是占位图。

服饰、发丝、绳索、武器挂件的次级运动随动作变化：起步滞后、急停前摆、落地回弹、转向跟随，幅度克制。呼吸和站姿有微变化，禁止整个人物周期性缩放冒充呼吸。

动作衔接覆盖跑转攻击、空中转攻击、攻击转闪避、闪避转跑、落地转连击、受击转死亡。保持轮廓可读，必要时补过渡姿势；混合不能让脚穿地、肢体旋转过大或攻击命中时武器尚未挥到。

## 场景与镜头

三区域各有独特材质和环境运动，不依赖全屏滤镜区分。玩法平台边缘、陷阱、门、可破坏物与装饰层有视觉语法。传送和出口有明确引导。

镜头包含速度前视、首领锁区和边缘约束；宽高比适配不露出未制作场景。前景必要时淡化，背景视差不干扰高速运动。攻击震屏、强光、残影、伤害数字可调，提供降低闪烁选项。

粒子、光照和后处理设数量预算与距离裁剪；全屏爆炸不得遮蔽敌人预警。颜色之外同时使用形状、动画或标志区别友军、敌方投射物和危险区域。

## 音频与界面

脚步按材质，挥空与命中不同，轻重伤害不同，技能充能、资源不足和冷却完成有反馈。音乐与环境声分层，连续重复音效限制叠加。音量设置分主音量、音乐、效果，可即时预览。

标题展示动态但低干扰的角色或场景；角色选择展示真实动作而非单张卡面。存档、难度、装备对比、增益选择、暂停、死亡和胜利界面统一排版，避免原始调试文本。完整中文字体与必要英文技术文字不乱码。

提供键位重映射、手柄提示自动切换、屏幕模式、分辨率、画质、震屏、闪烁与伤害数字设置。失焦自动暂停，窗口关闭按存档规范处理，设置即时保存且不写入活动局随机状态。

## Beta 验收

实际镜头尺寸逐项审核所有动作；静音状态仍能识别敌人预警；关闭震屏与粒子强化后战斗信息仍完整。1280×720、1920×1080 及约定宽高比无 UI 遮挡或文字截断。

至少邀请 3—5 名未参与实现的试玩者完成起始房和首个区域；记录误操作、看不懂的攻击、找不到出口与动作迟滞。自动测试不能替代手感反馈；若没有真人试玩，必须标为待验收，不能伪称已做。
