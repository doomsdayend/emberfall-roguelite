# 阶段 2 动作原型与基础闭环

目标：发布 v0.1.0，证明移动、跳跃、攻击与闪避形成可操作的战斗。美术允许占位，但必须表达姿势和时序，不能仅用静态方块代表动作。

## 最小可游玩范围

标题、开始游戏、简版设置、安全初始房间、训练区、2 个固定战斗房间、1 个测试首领或精英终战、胜利和死亡结算、暂停、返回标题、重新开始。1 名角色、1 种武器、2 种敌人。至少能连续完成两轮而不重启应用。

## 控制与运动

| 输入 | 默认键位 | 需求 |
| --- | --- | --- |
| 左右移动 | A/D 或方向键 | 加速与减速可调，松手反馈清楚 |
| 跳跃 | Space | 轻按短跳、长按高跳；单向平台向下穿越 |
| 普通攻击 | 鼠标左键 / J | 三段连击，输入缓冲，命中明确 |
| 技能 | 鼠标右键 / K | 阶段 2 可为简单重击，但须有独立动画 |
| 闪避 | Shift / L | 有资源或冷却约束，明确无敌时窗 |
| 交互 | E | 仅在交互范围触发，不与战斗输入冲突 |
| 暂停 | Esc | 停止战斗计时、AI 和伤害，继续无输入泄漏 |

初始调参：移动约 4.5—6H/s；跳跃高度约 2—2.5H；土狼时间 80—120ms；输入缓冲 100—150ms；闪避总长约 300—400ms，无敌段约 120—180ms。均须列出实际定值并通过试玩调整，不把范围直接写成不可解释的随机变化。

要求：低帧率下运动不明显变慢；斜坡、墙角、落地和单向平台无卡住；不能用关闭碰撞实现常规闪避；跳跃上升、最高点、下降和落地各有对应状态；翻向不重置连击或跳跃状态。

## 战斗和判定

普通连击包含预备、生效、收势，各段独立配置伤害、击退、命中框与动画事件。初值可采用 300/360/480ms 总时长，第三击更重；这些是动作设计起点，不是必须照搬的最终平衡。

受击区、攻击区、实体碰撞区分离。攻击命中由规定生效段驱动；同一攻击实例对同一目标默认仅结算一次。无敌期间不能扣血，死亡目标不能继续攻击。存在多个伤害来源时有清楚的叠加、免疫和受击优先级规则。

命中反馈包含轻重有别的停顿、受击姿势、音效、少量粒子与可关闭震屏。停顿建议轻击 30—50ms、重击 60—90ms 起测；不得让连续命中导致长时间无法操作或将暂停等同命中停顿。

敌人至少包括近战追击者和远程射手，均有察觉、接近或瞄准、预警、攻击、生效、恢复、受击、死亡。预警与攻击方向一致，不允许瞬间无提示命中。

## 原型验收

- 30/60/120 FPS 限制下分别验证移动距离、跳跃高度和攻击节奏；用可记录结果说明差异是否达标。
- 测试边缘起跳、松键短跳、落地缓冲跳、快速转向、被击中打断、连击接闪避和空中攻击。
- 进行至少 20 次房间重开和 10 次完整原型流程，未出现卡死、门不开、死亡后仍攻击或回标题失效。
- 暂停和失焦不会继续扣血；按住攻击返回游戏不触发意外攻击。
- 调试视图能显示碰撞框、动作状态、动画事件和攻击实例；玩家发布版默认隐藏。
