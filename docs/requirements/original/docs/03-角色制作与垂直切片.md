# 阶段 3 角色制作与垂直切片

目标：发布 v0.2.0。以 8—12 分钟短流程展示最终美术方向和战斗品质，同时验证角色资产生产流程。

## 范围

保留可玩闭环，完成 1 名最终品质主角、1 个最终品质武器家族、3 种敌人、1 个精英、1 名完整首领、1 个区域场景与 6—8 个房间模块。加入少量可改变战斗的增益供验证；本阶段仍可使用固定或有限随机流程，不提前承诺完整肉鸽系统。

## 主角制作

按附件 A 完成烬刃的模型设定、分层源文件、骨骼绑定或逐帧制作、全部基础动作、三段地面攻击、空中攻击、角色技能、武器插槽、受击与死亡。

必须提交“姿势预览”和“实机动作预览”：前者用于检查比例与轮廓，后者在实际镜头与场景中检查可读性、接地和方向。动画在干净背景上好看而实机看不清，不算通过。

骨骼制作须避免手臂拉长、肘膝反折、关节穿帮、衣服与身体脱节；头发、衣摆、披风有与速度一致的次级运动。攻击必须由腿、髋、躯干、肩、手臂共同发力，不能只有武器绕人物转圈。

## 敌人及首领

三类普通敌人至少覆盖近战、投射、位移。精英具备明显轮廓和独特行为。首领至少 3 个招式、明确预警与攻击后窗口；第二阶段改变行为组合，不能只把颜色变红和数值翻倍。

首领招式需求表记录：距离、朝向、预警时长、有效区、恢复时长、可闪避方式、打断与免疫规则、阶段切换。跳跃或闪避应有可理解的应对方式，不依赖事先背板才能判断伤害来源。

## 场景与反馈

完成背景远景、中景、玩法层、少量前景；近景遮挡人物时自动淡化或避免占据战斗区。环境有火焰、尘埃、草木等节制动态，运动方向与光源一致。

主角、敌人和背景形成亮度与轮廓区别。攻击特效贴合动作轨迹，刀光从真实武器挥动方向产生；脚步、落地、材质命中、击杀音效匹配事件。摄像机提供移动前视、有限纵向跟随、首领边界及轻量震动设置，不在落地时剧烈抖动。

## 通过条件

- 实机中能够一眼区分待机、跑步、闪避、攻击、受击和死亡。
- 动画源文件可修改与再次导出，模型规格、插槽、锚点、材质和命名符合附件 A。
- 以实机 1 倍尺寸录制完整关卡和动作展示；慢放检查攻击时窗与实际武器轨迹一致。
- 地面奔跑接地自然，攻击不改变身体尺寸，翻向不造成武器插槽错位。
- 首领预警、伤害范围、胜利门与结算均经过测试。
- 在阶段 1 确定测试机上测量运行表现，记录性能瓶颈和后续预算，禁止仅展示单张精美截图。

交付：v0.2.0 构建、模型设定与动画源文件、资产登记、切片演示、镜头与音画参数、品质审核及更新说明。此阶段通过后，才能按同一标准批量生产后续角色和敌人。
